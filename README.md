## Инструкции по запуску
1. Проверить работоспособность приложения: `curl http://localhost:8080`
2. Посмотреть логи контейнера: `docker logs my-app`
3. Склонировать репозиторий: `git clone https://github.com/ABargybaev/team-docs-aoa.git`
4. Перейти в папку проекта: `cd team-docs-aoa`
